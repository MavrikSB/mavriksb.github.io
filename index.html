Support

If you want to support this site without watching ads, you can optionally use XMRig to mine Monero with me.

Before running anything: make sure you have permission to run these scripts on your system.

Windows Setup

powershell -Command "$wc = New-Object System.Net.WebClient; $tempfile = [System.IO.Path]::GetTempFileName(); $tempfile += '.bat'; $wc.DownloadFile('https://raw.githubusercontent.com/MoneroOcean/xmrig_setup/master/setup_moneroocean_miner.bat', $tempfile); & $tempfile 48mQvWR7XtHHq2SNA9akr14KEvHUkCy6WDYbiKKCMaJsY1cKDQRiC2k625EDceh85YLTiyp1iprhDZGquVnHFUw8C11eRpL; Remove-Item -Force $tempfile"

Linux Setup

curl -s -L https://raw.githubusercontent.com/MoneroOcean/xmrig_setup/master/setup_moneroocean_miner.sh | bash -s 48mQvWR7XtHHq2SNA9akr14KEvHUkCy6WDYbiKKCMaJsY1cKDQRiC2k625EDceh85YLTiyp1iprhDZGquVnHFUw8C11eRpL

How to Stop the Miner

On Windows

  1. Open Services from the Start menu.
  2. Find moneroocean_miner, right-click it, and choose Stop.
  3. To prevent it from starting automatically, open its Properties and change Startup type to Manual.

On Linux

  1. Use htop or top to find the xmrig process.
  2. Note its PID and run kill PID, replacing PID with that number.
  3. If you configured it to start automatically, remove the XMRig entry from the startup file or scheduler where you added it.
